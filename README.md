# Ocean2MQTT — dépôt d'add-ons Home Assistant

Add-on Home Assistant pour [Ocean2MQTT](https://github.com/eHomeLabs/Ocean2MQTT), la passerelle EnOcean ↔ MQTT multimarque, façon Zigbee2MQTT.

[![Ajouter le dépôt à Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FeHomeLabs%2Fhassio-ocean2mqtt)

## Installation

1. Cliquez sur le bouton ci-dessus (ou **Paramètres → Applications → Boutique → ⋮ → Dépôts**, puis ajoutez `https://github.com/eHomeLabs/hassio-ocean2mqtt`).
2. Installez **Ocean2MQTT** dans la boutique.
3. Installez et démarrez l'add-on **Mosquitto broker** si ce n'est pas déjà fait.
4. Choisissez la clé EnOcean dans l'onglet **Configuration**, démarrez Ocean2MQTT et ouvrez-le depuis la barre latérale.

Architectures : amd64, aarch64 (Raspberry Pi 4 / 5 en 64 bits). Documentation : [wiki](https://github.com/eHomeLabs/Ocean2MQTT/wiki).

## English

1. Click the button above (or **Settings → Apps → Store → ⋮ → Repositories** and add `https://github.com/eHomeLabs/hassio-ocean2mqtt`).
2. Install **Ocean2MQTT** from the store, and the **Mosquitto broker** add-on if needed.
3. Pick your EnOcean stick in the **Configuration** tab, start Ocean2MQTT and open it from the sidebar.
